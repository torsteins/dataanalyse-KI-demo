# Demo of AI-Assisted Analysis Development with Sensitive Data

This repository is published as a worked example of using an AI coding
assistant (Claude Code) to help develop a data-analysis pipeline while
keeping the underlying sensitive dataset out of the AI's reach. It
accompanies a demonstration on how to combine AI-assisted development
with basic data-protection practices when working with sensitive,
individual-level data.

## Repository layout

- **`sensitive_area/`** — holds the real, individual-level patient data.
  Read and write access to this directory is blocked for the AI assistant
  via the permission and sandbox rules in
  [`.claude/settings.json`](.claude/settings.json), so the AI never sees
  the real data. It is also excluded via [`.gitignore`](.gitignore), so
  the real data is never committed to version control.
- **`dev_area/`** — where analysis code is developed and tested against a
  synthetic stand-in for the real data. This is the only data the AI
  assistant has access to.

## Dataset description

The (real) dataset tracks patients enrolled in a weight management
program. Each row is one pseudonymized patient, recording basic
demographics (birth date, sex, municipality code), enrolment date and
age at enrolment, height, the program track the patient was assigned to
(`standard` or `intensive`), baseline weight, weight at 12 months
(missing for patients who dropped out before completing the program),
and a free-text note field. See
[`dev_area/data_description.md`](dev_area/data_description.md) for the
full column-by-column description.

## Files in `dev_area/`

| File | Purpose |
|---|---|
| `data_description.md` | Documents the dataset's columns and known data-quality notes (e.g. that missing `weight_12m_kg` values mean drop-out, not a data-entry error). |
| `generate_dummy_data.py` | Generates a synthetic dataset with the same shape and column types as the real data, so that analysis code can be written and tested without exposing real patient data. |
| `dummy_data.csv` | The synthetic dataset produced by `generate_dummy_data.py`. |
| `analysis.py` | Compares 12-month weight loss between the `standard` and `intensive` program tracks (Welch's t-test), excluding patients who dropped out. Takes a CSV file path as its argument, so it can be run unmodified against either the dummy data or the real data. |

## Results

[`RESULT.txt`](RESULT.txt) (at the repository root) holds the output of
running `analysis.py` against the real data in `sensitive_area/`. This
step was run by a human with access to the real data — not by the AI
assistant.

## AI usage declaration

AI coding assistants were permitted to assist with software development in this repository — including writing and refactoring code, generating synthetic test data, and drafting documentation. All artifacts generated by AI has been manually verified by the authors.
